> **Turning Bold Ideas Into Powerful Digital Solutions.**

We engineer next-generation websites, custom software, and innovative technology solutions that empower businesses to compete, innovate, and grow globally.

---

## ✨ Features
- **Modern Floating Topbar**: Frosted glass floating navigation with soft rounded corners (`20px`), official Pryxon Studio branding, and smooth left-to-right animated hover underlines.
- **OriginKit "Cloud Sky" Background**: GPU-accelerated procedural volumetric cumulus cloud sky with real-time drift, wind, and mouse parallax.
- **3D Liquid Glass Tech Constellation**: 28 evenly distributed, butter-smooth floating tech badges (React, Next.js, Node.js, Python, FastAPI, Supabase, Tailwind, Vercel, Render, PostgreSQL, MongoDB, Angular, .NET, SQL, PHP, HTML5) with fluid multi-harmonic physics.
- **Ultra-Fast Performance**: Zero frame drops, 60–120 FPS butter-smooth rendering, optimized WebGL shaders and GPU-accelerated CSS compositing.
- **Zero-Config Vercel Ready**: Ready to deploy directly to Vercel with automated static routing and optimized caching headers.

---

## 🛠️ Tech Stack
- **Frontend**: HTML5, Modern CSS3 (Grid, Flexbox, Custom Properties), Vanilla JavaScript
- **3D / Shader**: Custom WebGL 2.0 / 1.0 Procedural Atmospheric Shader (OriginKit Cloud Sky)
- **Deployment**: Vercel Static Hosting

---

## 🚀 Local Development
To preview the website locally:

```bash
# Using npx serve
npx serve . -l 3000
```
Then visit `http://localhost:3000` in your browser.

---

## 🌐 Deploy to Vercel
1. Import this repository into [Vercel](https://vercel.com).
2. Framework Preset: **Other** / Static Site.
3. Root Directory: `./`
4. Click **Deploy**!
